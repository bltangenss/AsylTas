## Код және жинау

Android Studio-де `android` бумасын ашыңыз; `shared` жанында қалуы керек.

```powershell
.\android\gradlew.bat -p android :app:assembleDebug
python tools/qa_v4_core.py
```

Release үшін `JAVA_HOME`, `ANDROID_HOME`, `ASYL_KEYSTORE`, `ASYL_STORE_PASSWORD`
орта айнымалыларын баптап, `powershell -File tools/build_v4.ps1` іске қосыңыз.
Қол қою кілті/парольдер және жеке дерекқорлар бұл репозиторийге кірмейді.
Сайт коды мен іске қосу нұсқаулығы: [site_online](site_online/README_KZ.txt).
