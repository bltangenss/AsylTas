АСЫЛ ТАС — ОНЛАЙН САЙТ

48 тас түрі бар қазақша каталог, тіркелу/кіру, алқа жинау, сақталған жинақтар, таңдаулылар,
өтінімдер, пікірлер, хабарламалар және дүкенді басқару.
Бюджет/карат/мөлдірлік сүзгілері, үш тасты салыстыру, соңғы 12 қаралған тас,
жеке жазбалар және ЕҰУ маңындағы орындар үшін GPS қосылған.

Дизайн: HTML/CSS/JavaScript. Сервер: Cloudflare Worker. Дерекқор: D1.
Онлайн деректер жергілікті Android/Windows/сайт базаларынан бөлек.
Жергілікті қолданбадағы аккаунттар мен құпиясөздер интернетке көшірілмейді.
Фотосуреттер мен авторлық лицензиялар public/assets ішінде.
Медиа кітапхана браузердің IndexedDB қоймасында сақталады.

Қалыпты тіркелу клиент аккаунтын ашады.
Дүкен әкімшісі болу үшін сайт иесі Sites платформасындағы өз аккаунтымен
«Әкімшіні растау» сілтемесі арқылы алдымен кіріп, осы сайтта сол email-мен
тіркеледі. Содан кейін жеке кабинеттегі әкімші құқығын қосады.
Сервер сайт иесінің расталған тұлғасын тексереді.
SITE_OWNER_EMAIL мәні хостингтің құпия орта айнымалысында сақталады.
Кодта дайын құпиясөз немесе алғашқы келушіге автоматты әкімші құқығы жоқ.

Жинау:
  npm install
  npm run build
Тексерістер:
  npm test
Жергілікті Worker preview:
  npx wrangler d1 migrations apply DB --local
  npm run dev

Сайт Sites хостингінің source repository және version/deploy құралдары арқылы
жарияланады. .openai/hosting.json ішіндегі project_id мәнін өзгертпеңіз.
D1 SQL миграциялары drizzle бумасында. Қолданылған миграцияны өңдемей,
жаңа өзгерістерді келесі миграция файлына қосыңыз.

Каталог бағалары — оқу деректері. Үлгі: 6 тас, 5.90 карат, 616 200 теңге.
Алматы — үлгі мекенжай; телефон әдепкіде бос. Онлайн төлем қосылмаған.

АЙФОНДА ҚОЛДАНБА РЕТІНДЕ АШУ
Safari арқылы сайтты ашып, Бөлісу → На экран «Домой» → Добавить таңдаңыз.
«Открывать как веб-приложение» тетігі көрсетілсе, оны қосыңыз.
Басты экрандағы «Асыл тас» белгішесі қолданбаны браузер жолағынсыз ашады.
Төменгі бес бөлім: Басты, Каталог, Алқам, Өтінімдер, Профиль.
Қалған бөлімдер Профильде және басты беттегі қысқа сілтемелерде.

Қолданба белгішелері мен бет қаңқасы құрылғыға сақталады. Аккаунт,
өтінім және дерекқор өзгерістері интернетті қажет етеді; жеке API жауаптары
offline кэшке жазылмайды. Жаңарту белсенді форманы өздігінен қайта жүктемейді.

PWA тексеруі: node scripts/check_pwa.mjs
iPhone көрінісі: node scripts/iphone_test.mjs [сайттың HTTPS сілтемесі]
Бұл автоматтандырылған браузер тексеруі; нақты iPhone құрылғысын алмастырмайды.

4.0 КАТАЛОГ ЖӘНЕ GPS
Бастапқы 12 тастың ID, бағасы, салмағы өзгермейді; үлгі алқа бұрынғыдай.
Каталог 48 жазба ретінде D1 catalog_data кестесінде сақталады.
0001_catalog_and_discovery.sql — тек жаңа схема. 0000 өзгермейді.
Бірінші сұрауда бір атомдық batch каталогты толтырып, бұрынғы алқа, таңдаулы,
пікір кестелерін жаңа кеңейтілген кестелерге бір рет көшіреді. Ескі кестелер
өшірілмейді; аккаунттар, сеанстар, тапсырыс суреті және параметрлер сақталады.

Пушкин 9 — пайдаланушы таңдаған ЕҰУ маңындағы кездесу орны. Университеттің
ресми корпусы немесе дүкен деп көрсетілмейді. Пушкин 11 және Сәтбаев 2 —
бөлек университет бағдарлары. Дереккөздер campus_v4.json ішінде және бетте.
GPS тек батырманы басқанда браузер рұқсатымен сұралады. Координаталар
серверге/базаға жазылмайды және екі минуттан кейін құрылғы жадынан өшеді.
Қашықтық — түзу сызық бойымен жуық есеп. Нақты маршрут сыртқы картада
ашылады; пайдаланушы сол сілтемені басқанда ғана координаталар беріледі.

Жеке жазба, салыстыру және тарих аккаунт не жеке қонақ сеансына тиесілі.
Тіркелгенде қонақ деректерін көшіруді өзіңіз таңдайсыз. Қонақтың IndexedDB
медиасы жаңа сеанстан бөлек; аккаунттағы бұрынғы медиа атауы сақталады.
API, жеке жазба, GPS және аккаунт жауаптары Service Worker кэшіне кірмейді.
Автоматты сынақтар: npm test; браузер QA бөлек оқшау preview базасында.
